# Producto punto electoral

**Página publicada: https://produit-scalaire.github.io/producto_punto_electoral/**

Comparador de afinidades políticas para Colombia: sus respuestas y la importancia que les da forman un vector, que se compara por producto punto con las posiciones de los partidos en el Congreso 2022-2026.

Adaptación al caso colombiano del [Produit scalaire électoral](https://github.com/produit-scalaire/produit-scalaire-electoral).
